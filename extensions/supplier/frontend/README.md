# 供应商门户

独立Vue3/TS/Vite工程，复用现有API客户端/i18n，不修改主站frontend或web/dist。

当前R2 D1：供应商本地账户登录；平台管理员独立认证（包括已有主站2FA）；供应商列表/开户/资料/启停/密码重置及指定供应商账号读取。仅真实身份决定权限，无评审角色切换。账号池写入、代理、用量、财务仍明确显示未接入，无模拟数据。

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run dev
```

Node/pnpm以package.json和锁文件为准。Vite默认127.0.0.1:5174，开发代理本地8091；已配置的Docker本地环境也占5174时不要同时启动Vite。

供应商路径 `/`；管理员登录 `/?portal=admin`。表单不存储或回显密码；提交后立即清除。后台校验Origin/CSRF、实际管理员与supplier范围，前端选择入口不是授权。Cookie不跨域，不在localhost和127.0.0.1间混用。

旧S1/S2组件及测试暂留供后续账号流程复用，当前App不启用旧Identity/Review导航。生产仅使用R2 API；主站2FA或合规门控不自动绕过。

## 本地供应商手动接入

账号池的添加按钮打开真实 OAuth 弹窗；先选择/创建并检测自有公网代理和配置分组，再在官方页面亲自授权。授权码、代理认证不进入浏览器持久化存储，提交后清空。新账号成功后保持暂停；自动授权、启停、共享/批量代理和用量尚未完成。代理初始容量为 1，取消未消费的授权会释放预留，结果未知保留占用等待核对。只在隔离环境验证，真实 Claude 仍需人工补验。

新增代理检测未通过时保留弹窗并明确提示已保存为无效记录；复检使用已有 ID，只有有效结果才关闭或进入账号接入。结果未确认时禁止重复提交。新记录展示规范化后的原始域名/端口并移除认证信息，实际连接保留域名，新增、复检及授权前检查 DNS 公网地址；历史记录不反查或猜测原域名。
