# S2：Claude 接入与账号池实施记录

执行授权：2026-10-22，按已确认计划持续实施。业务源码、测试和可复用工具均位于本项目 `extensions/supplier/`；仓库外仅保存临时探针、原始输出、备份及私有运行配置。

## 执行边界与验收

- 一个供应商一个登录身份，首期仅 Claude OAuth；不恢复多人角色、成员管理和供应商开户运营门户。
- 先交付账号接入、账号池、待审核隔离、平台审核和暂停，再实现所有账号用量及代理管理。
- 主站 `backend/`、`frontend/` 和生产实例不修改。只有独立模块使用自己的前向迁移。
- 管理密钥只在服务端，配置缺失时失败关闭；供应商不获得主站管理密钥。
- 新账号只创建在经过检查的专用隔离组，确认关闭调度后才显示待审核；平台审核后再绑定批准分组并最后开启调度。
- OAuth 会话绑定供应商、操作者、state、截止时间且单次消费；不收取用户手工粘贴的长期 Token。结果未知不自动重放换码或创建。
- 通过模块自己的主键和身份指纹去重，不以主站 notes/extra 证明归属；所有供应商读取/暂停操作校验归属。
- 平台账号审核是窄业务权限，不等于供应商开户/成员管理。审核请求还必须持当前有效主站 admin 身份。
- 模拟 OAuth、实际本地 Sub2API/PG 和故障测试先执行；真实 Claude 授权/刷新和模型调用单列待验收，不宣称已经通过。

## 已完成的前置验证

真实本地网关探针观察：待审核账号未到达测试代理，批准后到达测试代理一次；代理拒绝 CONNECT，未连接真实 Claude。创建重放返回相同账号，同键异请求返回409。本地主站管理员合规门控已由用户自行完成，管理接口读取为200。
